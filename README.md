# next-community-2027 — marketingNEXT membership brochure

Client-facing single-page brochure for **marketingNEXT**, the monthly
peer-led marketing surgery for senior iGaming marketers. Sells one product:
annual membership at €4,000 per company per year (flat, no tiers).

Built with Vite + React + Tailwind v4. All copy lives in content arrays at
the top of `src/App.jsx`.

```
npm install
npm run dev      # local preview
npm run build    # verify it compiles
npm run deploy   # build + publish dist/ to gh-pages
```

Live at https://nextdotio.github.io/next-community-2027/ once GitHub Pages
is enabled for the repository (Settings → Pages → deploy from `gh-pages`).

Content and branding rules — including the list of internal-only material
that must never reach this page — are in `CLAUDE.md`.
